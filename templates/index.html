Chrome Extension ↗

One-click download from any YouTube page:

  1. Download ALACarrte-Chrome-Extension.zip and unzip it
  2. Open Chrome to chrome://extensions
  3. Enable Developer mode (top-right toggle)
  4. Click Load unpacked and select the unzipped folder
  5. Pin the extension — click it on any YouTube page to download as ALAC
